# 数组与链表

> 本章目标：理解数组和顺序表的概念、区别，以及为何需要链表

## 生活化类比

**数组**就像一排紧挨着的停车位：
- 每个车位都有固定编号（0, 1, 2...）
- 你知道自己的车停在哪个位置，可以**直接**走过去
- 但如果要在中间插入一辆车，要移动后面所有车

**链表**就像游乐场排队：
- 每个人记住后面那个人是谁（指针）
- 要找某个人，必须从第一个人开始一个个问过去
- 但要在中间插入一个人，只需要改两个人的"指向"就行

## 核心概念

### 1. 数组（Array）

数组是最基本的数据结构，在内存中是**连续存放**的：

```
内存地址:    0x01   0x02   0x03   0x04   0x05
数组元素:    [ 10 ] [ 20 ] [ 30 ] [ 40 ] [ 50 ]
索引:         0      1      2      3      4
```

**特点**：
- 支持随机访问：通过下标 O(1) 时间找到任意元素
- 插入/删除效率低：需要移动大量元素
- 长度固定（静态数组）

### 2. 顺序表（Sequential List）

用数组实现的**线性表**，封装了插入、删除、查找等操作：

| 操作 | 时间复杂度 | 说明 |
|------|-----------|------|
| 按索引访问 | O(1) | 直接计算偏移量 |
| 在尾部插入 | O(1) | 数组有空位时 |
| 在中间插入 | O(n) | 需要移动元素 |
| 查找 | O(n) | 逐个比较 |

### 3. 链表（Linked List）

分为**单向链表**和**双向链表**，这里先讲单向链表：

```
头节点
  │
  ▼
┌────┬───┐  ┌────┬───┐  ┌────┬───┐  ┌────┐
│ 10 │ ──┼─►│ 20 │ ──┼─►│ 30 │ ──┼─►│None│
└────┴───┘  └────┴───┘  └────┴───┘  └────┘
```

**节点包含**：
- `data`：存储的数据
- `next`：指向下一个节点的指针（None 表示链表结束）

**特点**：
- 不支持随机访问：要从头逐个遍历 O(n)
- 插入/删除效率高：只需修改指针 O(1)
- 长度灵活：可以动态增长

### 4. 数组 vs 链表

| 对比项 | 数组 | 链表 |
|--------|------|------|
| 存储方式 | 连续内存 | 分散内存（靠指针连接） |
| 访问方式 | 随机访问 O(1) | 顺序访问 O(n) |
| 插入/删除 | O(n) | O(1)（已知位置时） |
| 空间效率 | 高（无额外开销） | 低（需要存指针） |
| 实现难度 | 简单 | 稍复杂 |

## 应用场景

### 什么时候用数组？
- 需要频繁**随机访问**元素
- 数据量固定，不太需要插入/删除
- 例：成绩查询、矩阵运算、排序算法中间结果

### 什么时候用链表？
- 需要频繁**插入/删除**元素
- 数据量不确定，需要动态增长
- 例：任务队列、浏览器前进/后退功能、哈希表解决冲突

## 考试重点

1. **数组下标计算**：一维数组元素地址 = 首地址 + 索引 × 元素大小
2. **链表指针操作**：画图理解指针修改，特别注意头节点和尾节点的边界情况
3. **时间复杂度分析**：能说出各种操作的时间复杂度

## 常见考点和易错点

### 易错点 1：数组下标从 0 开始
```python
arr = [10, 20, 30]
arr[0]  # 第一个元素，不是 arr[1]
```

### 易错点 2：链表遍历结束条件
```python
current = head
while current is not None:  # 不是 current.next is not None
    current = current.next
```

### 易错点 3：插入节点的顺序
插入节点时，**先接后断**：
```python
new_node.next = current.next  # 先让新节点指向后继
current.next = new_node       # 再让当前节点指向新节点
```
如果顺序搞反，就会丢失后面的链表！
