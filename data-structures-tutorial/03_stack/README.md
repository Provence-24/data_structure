# 栈（Stack）

> 本章目标：理解栈的"后进先出"特性，能用手写代码实现栈，了解栈的实际应用

## 生活化类比

**羽毛球筒**：
- 羽毛球一个一个放进去，先放进去的球在筒底，后放进去的球在筒口
- 拿出来时，先拿的是最后放进去的（筒口的球）
- **后进先出（Last In First Out, LIFO）**

或者**网页浏览器的"后退"按钮**：
- 你先访问 A，再访问 B，再访问 C
- 点后退按钮时，先回到 B，再回到 A
- 历史记录就是一个栈

## 核心概念

### 栈的结构

```
栈顶（top）
  ─────
  │ 30 │  ← 最后放入，最先取出
  ├─────┤
  │ 20 │
  ├─────┤
  │ 10 │  ← 最先放入，最后取出
  ├─────┤
  │    │
  ─────
栈底（bottom）
```

**两种视角**：
- **线性表视角**：栈是一种特殊的线性表，只能在一端（栈顶）进行操作
- **LIFO 视角**：最后进来的最先出去

### 基本操作

| 操作 | 作用 | 时间复杂度 |
|------|------|-----------|
| push(item) | 把元素压入栈顶 | O(1) |
| pop() | 弹出栈顶元素 | O(1) |
| peek() / top() | 查看栈顶元素（不弹出） | O(1) |
| is_empty() | 判断栈是否为空 | O(1) |
| size() | 返回栈的大小 | O(1) |

### 为什么栈重要？

1. **函数调用栈**：函数调用时局部变量存在栈里，递归其实就是栈的应用
2. **括号匹配**：编译器用它来检查语法错误
3. **表达式求值**：计算器（中缀转后缀）
4. **撤销操作**：编辑器的 Ctrl+Z 用栈实现

## 应用场景详解

### 1. 括号匹配

检查表达式中的括号是否成对出现：

```
输入: "((a + b) * c)"   输出: 匹配
输入: "(a + b) * c)"     输出: 不匹配
输入: "((a + b] * c)"    输出: 不匹配
```

**算法**：
1. 从左到右扫描每个字符
2. 遇到左括号 `(` `[` `{`，压入栈
3. 遇到右括号 `)` `]` `}`，弹出栈顶检查是否匹配
4. 扫描结束后，栈为空则匹配

### 2. 中缀转后缀表达式

人习惯写中缀表达式 `3 + 4 * 2`，但计算机处理后缀表达式更方便 `3 4 2 * +`。

**算法**（用栈实现）：
1. 从左到右扫描中缀表达式
2. 遇到操作数，输出
3. 遇到左括号，压入栈
4. 遇到右括号，弹出栈顶直到左括号
5. 遇到操作符，按优先级处理

## Python 实现

```python
class Stack:
    def __init__(self):
        self.items = []

    def push(self, item):
        self.items.append(item)  # 列表末尾是栈顶

    def pop(self):
        if self.is_empty():
            return None
        return self.items.pop()

    def peek(self):
        if self.is_empty():
            return None
        return self.items[-1]

    def is_empty(self):
        return len(self.items) == 0

    def size(self):
        return len(self.items)
```

**注意**：用 Python 列表的 `append()` 和 `pop()` 实现栈非常方便（都是 O(1)）。

## 常见考点和易错点

### 易错点 1：栈空时 pop

```python
def pop(self):
    if self.is_empty():
        raise Exception("栈为空！")
    return self.items.pop()
```

### 易错点 2：混淆栈顶和栈底

- 栈顶 = 最后放入元素的位置 = 列表末尾（用 `append()` 的一端）
- 栈底 = 第一个放入元素的位置 = 列表开头

### 易错点 3：括号匹配不处理右括号多余的情况

扫描结束后，还要检查栈是否为空：
```python
if not stack.is_empty():
    return False  # 左括号多余
```
